🛡️ SentinelAgent

A deny-by-default security gateway for AI agents. It checks tool calls going out, guards tool output coming back, and holds risky calls for a human. This page runs the real sentinel package from main in your browser with Pyodide. No server, nothing leaves the page.

Multi-agent demo

A researcher agent and a mailer agent summarise a release-notes page that contains a hidden instruction to email the customer list to an outside address. A reviewer agent screens every held call and can only reject or escalate. The model turns are scripted here, and the researcher is written to fall for the injection. Everything else (gateway, taint tracking, approvals, audit ledger) is the real code. Escalations are auto-approved as the human.
